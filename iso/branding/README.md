# Branding Assets

Place the following files here for ISO branding:

- `plymouth/` — Boot splash theme
  - `openplank.png` — 1920x1080 splash image
  - `openplank.plymouth` — Plymouth theme config
  - `openplank.script` — Plymouth animation script
- `wallpaper.png` — Default desktop wallpaper (1920x1080)
- `logo.svg` — openPlank logo (vector)
- `icon.png` — App icon (256x256)
- `grub-splash.png` — GRUB bootloader background (1920x1080)

All assets should use the openPlank color palette:
- Primary: #5B9AA0 (Teal)
- Background: #0F172A (Dark Slate)
- Text: #F8FAFC (Almost White)
- Accent: #7DD3FC (Light Blue)
